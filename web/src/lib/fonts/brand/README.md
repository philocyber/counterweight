# Console brand fonts

Instrument Sans (variable, 400 to 700) and Geist Mono (400, 500) are self-hosted
through `next/font/local`, including in embedded builds. The UI uses Instrument
Sans for controls and body text; Geist Mono is reserved for code, identifiers
and measurements.

Both families use the SIL Open Font License 1.1. The original notices are retained
in `OFL-InstrumentSans.txt` and `OFL-GeistMono.txt`.

Upstream: [Instrument Sans](https://github.com/google/fonts/tree/main/ofl/instrumentsans),
[Geist](https://github.com/vercel/geist-font).
